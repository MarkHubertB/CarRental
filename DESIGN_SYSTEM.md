# 💎 CarRental 2026 Luxury Design System

This document defines the visual and functional standards for the world-class redesign of the CarRental platform.

## 🎨 Visual Language
**Aesthetic**: Dark Opulence. An immersive, high-contrast experience that mirrors the feeling of a luxury showroom.
**Core Principles**:
- **Cinematic**: Large, high-fidelity imagery and video.
- **Precise**: Clean lines, generous whitespace, and a structured Bento grid layout.
- **Tactile**: Glassmorphism, subtle gradients, and fluid micro-interactions.

## 🌈 Color Palette
| Role | Hex | Name | Usage |
| :--- | :--- | :--- | :--- |
| Primary | `#D4A843` | Champagne Gold | Primary CTAs, active states, luxury accents. |
| Secondary | `#F0C96A` | Soft Gold | Hover states, accent borders, highlights. |
| Background | `#0A0A0A` | Obsidian Black | Main page backgrounds. |
| Surface | `#1A1A1A` | Dark Slate | Cards, modals, input fields. |
| Text High | `#FFFFFF` | Pure White | Headings, primary labels. |
| Text Low | `#A1A1AA` | Muted Slate | Body text, descriptions, captions. |

## ✍️ Typography
- **Headings**: `DM Serif Display` (High-contrast Serif) - Evokes prestige and luxury.
- **UI/Body**: `DM Sans` (Modern Sans-Serif) - Clean, wide, and professional.

## 🛠️ Component Blueprint
### 1. Hero Section
- Full-bleed background (Cinematic).
- Floating glassmorphic search widget.
- Minimalist navigation with transparent background.

### 2. Fleet Display
- **Bento Grid**: Varied card sizes to highlight "Featured" vehicles.
- **Interactive Cards**: Hover effects that reveal quick-specs (top speed, fuel type).

### 3. Booking Experience
- **Multi-step Wizard**:
  1. Vehicle Selection $\rightarrow$ 2. Premium Add-ons $\rightarrow$ 3. Customer Info $\rightarrow$ 4. Confirmation.
- **Dynamic Pricing**: Real-time total calculation as options are selected.

### 4. Admin Command Center
- **Dark Dashboard**: High-contrast data visualization.
- **Fleet Management**: Table-based view with quick-action status toggles.

## 🚀 Premium Features
- **Comparison Tool**: Side-by-side spec comparison modal.
- **Immersive Gallery**: Full-screen, high-res image slider with zoom capability.
- **Customer Portal**: Simplified "My Rentals" dashboard.
